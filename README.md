# MatheLab

Eine hochmoderne, animierte und vollständig responsive Mathematik-Lernwebsite –
für Smartphone, Tablet, Laptop und Desktop. Alles in einer einzigen Datei,
ohne externe Abhängigkeiten (Schriften sind eingebettet, funktioniert offline).

## Öffnen

Einfach `index.html` im Browser öffnen (Doppelklick) – keine Installation, kein Server nötig.

## Funktionen

- **Animierte Hero-Tafel** – Funktionsgraphen zeichnen sich von selbst.
- **Funktionsplotter** – zwei Funktionen gleichzeitig, Zoomen (Mausrad / zwei Finger),
  Verschieben durch Ziehen, Live-Ablesen der Koordinaten.
  Versteht `sin, cos, tan, sqrt, log, ln, abs, ^, pi, e` und Kurzschreibweisen wie `2x`.
- **Mathe-Trainer** – unendlich viele Aufgaben in 7 Bereichen
  (Addition bis Gleichungen) und 3 Schwierigkeitsgraden, mit Punkten, Serie und Trefferquote.
- **6 Lektionen** – Algebra, Geometrie, Funktionen, Analysis, Stochastik, Trigonometrie –
  jeweils mit Kernformel, durchgerechnetem Beispiel und Merksatz.
- **Formelsammlung** – über 40 Formeln in 6 Gebieten zum Aufklappen.
- **Hell-/Dunkelmodus**, Scroll-Animationen, `prefers-reduced-motion` wird respektiert.
- **Fortschritt** wird lokal gespeichert (localStorage), keine Anmeldung nötig.
